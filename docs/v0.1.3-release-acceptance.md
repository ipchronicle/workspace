# v0.1.3 发布验收

## 发布状态

`v0.1.3` 于 2026-10-02 正式发布。

- [正式版本](https://github.com/ipchronicle/ipchronicle/releases/tag/v0.1.3)
- [正式发布工作流](https://github.com/ipchronicle/ipchronicle/actions/runs/36965044703)
- [候选验证工作流](https://github.com/ipchronicle/ipchronicle/actions/runs/36962649750)
- [普通 CI](https://github.com/ipchronicle/ipchronicle/actions/runs/36962625366)

Release 不是草稿，也不是预发布版本。GHCR 中的
`ghcr.io/ipchronicle/ipchronicle-center:v0.1.3` 和 `latest` 均为多架构镜像，包含
`linux/amd64` 与 `linux/arm64`，两者的 OCI 摘要一致：
`sha256:f273cdbd530a9988604271472813112bffafe9bcf63b00bfc3d7af68f8ce2880`。

## 本次变更

- NAT 仍保留在内部诊断数据中，但不再作为用户可见状态、首页关注项、公网 IP 状态、
  探测目标或 Telegram 通知内容。
- 更新前端传递依赖，普通依赖审计通过。
- 不修改 `v0.1.1` 已发布迁移，也不要求重置 Center 或 Agent 数据。

## 验证范围

普通 CI、候选验证和正式发布流程均通过，候选验证覆盖浏览器、Compose、升级、资源限制、
发行版矩阵、CentOS Stream 和可复现构建。问题 10（ipapi 结果缺失）与问题 11（发现、
NAT 判断和探测目标不一致）仍需线上受影响节点的详细日志确认，本次发布没有宣称这些问题
已经解决。
