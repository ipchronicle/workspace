# v0.1.4 发布验收

## 发布状态

`v0.1.4` 于 2026-10-03 正式发布。

- [正式版本](https://github.com/ipchronicle/ipchronicle/releases/tag/v0.1.4)
- [正式发布工作流](https://github.com/ipchronicle/ipchronicle/actions/runs/37110063812)
- [候选验证工作流](https://github.com/ipchronicle/ipchronicle/actions/runs/37108089608)
- [普通 CI](https://github.com/ipchronicle/ipchronicle/actions/runs/37107776339)

Release 不是草稿，也不是预发布版本。GHCR 中的
`ghcr.io/ipchronicle/ipchronicle-center:v0.1.4` 和 `latest` 均为多架构镜像，包含
`linux/amd64` 与 `linux/arm64`，两者的 OCI 摘要一致：
`sha256:b5475fdcfa53990aad11c8c1fc5a3463c46e19b6adfde2bdf3a36c755e154639`。

## 本次变更

- 通知规则新增“全部事件”和按事件排除，并通过有序配置迁移保存既有配置与历史。
- 快照比较页使用真实时间轴，默认最早与最新快照，支持连续滑动和即时报告切换。
- 清理未使用的 shadcn CLI 依赖链，修复依赖审计发现。
- Web 资源变化纳入 AMD64 镜像验证范围；发布流程仍验证双架构镜像。

## 验证范围

普通 CI、候选验证和正式发布流程均通过。候选验证覆盖源码检查、浏览器、Compose、
失败恢复、发行版与架构矩阵、资源限制、可复现构建和从稳定版数据的升级门禁。
ARM64 资源门禁首次运行出现约 20 KiB 的瞬时峰值超限，单独重跑后通过；没有放宽
64 MiB 限制。

问题 10（ipapi 结果缺失）与问题 11（发现、NAT 判断和探测目标不一致）仍需线上
受影响节点的详细日志确认，本次发布没有宣称这些问题已经解决。
