# IPChronicle UI 信息架构

Status: Accepted first-release baseline

Date: 2026-08-07

## 目的

本文记录 IPChronicle 首版管理员界面已经确认的信息架构。它定义页面职责与
核心导航关系，不替代产品定义、系统架构、API 契约或具体视觉设计。

尚未确认的页面、路由名称和交互不得因示例模板或脚手架默认值写成既定结构。
官方 shadcn/ui block 只提供组件和布局起点，不决定本产品的信息层级。

## 已确认原则

- 第一屏是实际管理界面，不提供营销 Landing Page。
- 登录后的默认页面是全局状态总览。
- 总览面向“现在有什么需要关注”，不是展示通用商业指标的分析仪表盘。
- 总览与节点列表职责分开。总览提供跨节点摘要和异常入口，节点列表承担完整
  浏览、筛选和节点级管理。
- 常态信息保持紧凑克制，失败、离线、变化、资源限制和格式异常获得更高视觉
  优先级。
- 总览中的聚合状态必须能够进入所属节点、公网 IP、探测执行或配置详情，
  不能成为没有下钻路径的统计卡片。
- 简体中文与英文界面必须保持相同的信息层级和操作能力；文本长度差异不能
  改变功能可达性。

## 一级导航

首版一级导航固定为：

- 总览 / Overview；
- 节点 / Nodes；
- 历史记录 / History；
- 通知 / Notifications；以及
- 设置 / Settings。

地址变化和完整探测报告归属于全局唯一的公网 IP，并保留执行节点来源，不作为
两个独立一级入口。
“历史记录”是跨节点索引，内部使用“探测报告”和“地址变化”两个独立标签页；
它不建立重复的数据所有权。进入具体记录后必须保留或恢复公网 IP、执行节点与
时间上下文。

全局历史只提供跨节点浏览和筛选。公共筛选包括节点、公网 IP 和时间范围；
“探测报告”可按运行结果、触发来源、字段变化和格式异常筛选；
“地址变化”可按事件类型和地址族筛选。首版不提供任意 JSON 字段查询、SQL 式
条件组合、全文索引或保存筛选方案。

## 节点与公网 IP

节点详情使用以下五个内部入口：

- 节点概览；
- 公网 IP；
- 探测报告；
- 地址变化；以及
- 节点设置。

节点级“探测报告”展示完整探测运行。一次运行保留其冻结的公网 IP 集合和每个 IP
的子执行结果，不能在界面中拆成没有共同运行上下文的独立报告。节点级“地址
变化”聚合由该节点观察到的事件。无法可靠归属公网 IP 的队列缺口只显示为节点级
缺口，不能暗示属于某个 IP。

“公网 IP”显示该节点当前能够到达的去重地址；相同 IP 即使由多个接口、源地址、
NAT、代理或节点发现也只作为一个对象。卡片只显示地址、地址族、可用性、当前
执行节点、NAT 或代理提示和完整探测开关。接口、路由、源地址、选择器和自动
路径 UUID 不进入浏览器响应或页面。

代理作为节点“公网 IP”页上的次级管理对象创建、编辑和删除。添加 HTTP、HTTPS
或 SOCKS5 代理后，Agent 自动尝试通过它发现 IPv4 和 IPv6 公网出口；用户不选择
地址族，也不管理内部代理路径。页面显示代理自身状态以及 IPv4、IPv6 各自的发现
结果或不可用状态，并据此显示检测中、仅 IPv4、仅 IPv6、双栈或暂不可用。单栈
状态只表示当前确认结果，失败的地址族仍按轻量检查周期重试。删除代理不删除已
发现公网 IP、报告或已经归属的地址历史。新发现公网 IP 默认启用完整探测，但首
次发现本身不立即执行；管理员可以逐个停用。

节点的探测设置提供一个默认开启的“发现新 IP 后自动完整探测”开关。系统比较
节点前后两次成功确认的去重公网 IP 集合，只对新增且已启用的地址执行一次完整
探测，不会重跑其他当前公网 IP。隐藏路径的变化不建立两个 IP 之间的替换关系。
首次建立路径基线以及检查失败后恢复为同一确认集合不触发；一个 IP 是否曾经
出现过不改变后续进入当前集合时的触发行为，已有身份和历史按规范化 IP 关联。

节点级“立即完整探测”入口先打开目标确认框，只列出当前可用且由该节点负责执行
的公网 IP。已经启用的地址默认选中；管理员可以在确认框中调整选择。“保存并开始
探测”必须在同一中心操作中持久化所选目标并创建即时任务，不能要求管理员先进入
公网 IP 页面逐个启用。保存后的目标同时用于本次和周期探测；节点级新增地址策略
只考虑其中已启用的新地址。没有选择任何目标时不能创建任务，节点注册本身仍不
触发完整探测。

全局历史、节点详情与公网 IP 报告是同一批记录的不同过滤上下文，不建立重复数据
所有权。从全局记录进入详情时应直接到达相应节点、公网 IP 或运行，并保留合理的
浏览器返回路径。

## 探测运行、报告与比较

报告工作流分为三个页面层级：

1. 节点级探测运行详情；
2. 公网 IP 成功快照详情；
3. 同一公网 IP 的快照比较页。

探测运行详情保留一次手动、计划或地址变化触发的整体上下文，显示触发来源、
开始与结束时间、整体状态、冻结的公网 IP 顺序，以及每个 IP 子执行的状态。部分
成功必须同时显示成功快照和失败或跳过的兄弟执行，不能把一次多出口运行展示
成数次没有关联的探测。

只有成功的公网 IP 执行产生可查看的报告快照。快照详情默认显示面向管理员阅读的
语义化报告，将基础信息、风险评分、风险因子、流媒体与 AI、邮件与黑名单按
章节组织。主报告沿用上游报告的字段分组、顺序和矩阵关系：使用类型与公司类型
属于 IP 类型属性，数据库地区作为风险因子的第一行，风险因子和流媒体结果均
按上游的“项目 × 数据源”矩阵展示。界面可以使用 IPChronicle 的卡片、响应式
滚动和本地化样式，但不能重新归类、汇总或改变字段之间的关系。报告中的绿、黄、
红状态色沿用上游各字段的语义和各风险数据库自己的分级阈值，不使用跨数据库的
统一评分阈值；DNS 黑名单总数沿用上游青色。完整原始 JSON
保留为次级视图。缺失、类型不兼容和未知字段进入仅在存在问题时显示的格式诊断
视图，不以大量空字段污染主报告；失败执行只显示失败阶段、状态和有界脱敏诊断，
不生成空报告或伪造字段。
已知字段的 JSON `null` 表示上游数据源没有返回结论：矩阵位置使用中性占位符，
不显示为肯定或否定状态，也不进入格式诊断。路径缺失和非空错误类型仍属于格式
异常。

成功快照可以复制到剪贴板或导出为 PNG。图片包含快照概览和完整语义化报告，沿用
当前界面语言、主题、字段矩阵和状态色；不包含站点导航、页面操作、原始 JSON 或
格式诊断。图片使用固定桌面报告宽度，不因发起操作的浏览器视口而裁掉矩阵列。

快照比较使用独立、可导航的全宽页面，不放入弹窗或临时抽屉。页面以公网 IP
为比较范围，进入后默认选择该 IP 当前仍被保留的最早和最新快照，使管理员先
看到整个保留区间的累计变化。顶部使用一条双端时间轴展示所有真实快照点，两个
端点只能吸附到实际快照；管理员可以自由调整比较的起始和终止时间。历史列表只
提供进入所属公网 IP 快照比较的直接入口，不要求先选第一份、再到另一行完成配对。
时间范围控制条在浏览报告时固定于应用顶栏下方，使管理员滚动到报告任意位置后
仍可直接调整起止快照；吸顶状态使用紧凑布局，不能长期遮挡大块报告内容。

下方使用与快照详情相同的完整语义化报告布局：桌面并排显示起始与终止报告，
移动端按起始、终止纵向排列。发生变化的字段在两份报告的原始位置同时高亮，
不拆成脱离报告上下文的逐字段差异卡。缺失、类型不兼容和历史缺口仍与普通语义
变化明确区分；历史缺口同时标记在时间轴上。只有一份保留快照时明确提示无法
比较。“最早”和“最新”始终指保留策略执行后当前仍存在的边界快照。

## 搜索、筛选与批量操作

首版不提供全局命令面板、跨资源全文搜索或任意字段查询。顶栏不为了匹配示例
模板而保留没有明确产品用途的全局搜索框。

节点列表提供局部文本搜索，覆盖节点名称和当前公网地址；状态
筛选覆盖在线、离线、警告、禁用、配置未同步和存在 Agent 更新。历史记录使用
已经定义的节点、公网 IP、时间、运行结果、触发来源、地址事件和地址族筛选。

跨节点批量操作首版只提供管理员触发的 Agent 更新，这是已确认的分组操作。
手动完整探测、启用或禁用、永久删除和配置修改保持在单个节点或公网 IP 上下文，
不通过通用批量工具扩展任务与危险操作语义。

顶栏只保留全局可达且高频的语言、明暗主题、管理员账户和当前系统级警告入口。
页面级搜索、筛选和操作保留在拥有相应数据的页面标题或工具栏区域。

## 设置与危险操作

一级“设置”只管理安装级或管理员级全局配置，不作为节点、公网 IP 和通知配置的
集中入口。首版分组为：

- 账户与安全：用户名、密码、TOTP、语言偏好和会话控制；
- 系统：Center 版本、发布通道、可自动跟随当前浏览器地址的外部访问设置、
  反向代理配置状态和 HTTP 风险；
- 网络探测：安装级轻量地址发现服务；以及
- 历史与存储：保留策略、逻辑用量、超额状态和清空历史。

由 Compose 环境或服务器操作者拥有的系统值可以在界面中显示当前状态与配置
来源，但不能为了统一外观虚构一个无法可靠持久化的网页编辑入口。

通知不放入全局设置。一级“通知”页面内部管理通知规则、Telegram、Webhook
与 JavaScript senders，以及发送记录。节点安装命令属于节点列表，Agent 更新
属于节点上下文。

节点名称、时区、完整探测计划、发现新 IP 后自动完整探测、资源警告覆盖和节点启用
状态属于节点设置。时区使用可搜索的 IANA 时区下拉框；新节点默认使用生成注册密钥
时管理员浏览器报告的时区，不显示或保存 Agent 本机时区占位值。
节点设置同时提供保留本地状态的 Agent 卸载命令和删除本地状态的完整卸载命令；
两者都只供服务器操作者在所属主机执行，不从浏览器远程下发。公网 IP 探测开关
以及代理和凭据管理属于相应节点的“公网 IP”页。

永久删除节点放在所属设置页面底部的危险区域；删除代理放在节点“公网 IP”页；
清空历史放在“历史与
存储”的危险区域。危险操作必须显示影响范围并进行明确确认，不能集中到脱离
对象上下文的全局危险操作页面。删除通知 sender 等其他对象同样保留在所属
对象上下文。

## 响应式呈现

桌面和移动端共享同一信息架构与功能能力，但移动端不把桌面宽表格和并排视图
等比缩小。

- 桌面使用可折叠侧栏；移动端由顶部菜单按钮打开基于 shadcn/ui `Sheet` 的
  导航，不增加另一套底部导航。
- 节点与历史表格在移动端使用优先字段列表，首先显示名称、状态、地址、时间
  和主要结果；完整信息通过详情页获得。
- 次要表格列不能依靠压缩字体或整页横向滚动强行保留。筛选在移动端进入专用
  面板，并在列表上明确显示当前生效条件。
- 原始 JSON 使用独立等宽代码区域，支持换行切换、局部横向滚动、复制和下载，
  不通过缩小字体容纳长行。
- 快照比较在足够宽的桌面视口并排显示两份完整报告，在移动端按起始、终止
  纵向排列；变化字段在原报告位置高亮，时间轴在两种视口下保持相同选择能力。
- 安装命令、诊断和不可断开的地址或标识符允许在自身区域横向滚动，不能截断
  或挤压相邻内容。
- 低频操作可以进入详情页操作菜单，但危险操作的影响说明和确认步骤在移动端
  同样完整。

## 全局状态总览

总览至少覆盖以下信息：

- 在线、离线和配置应用异常的节点；
- 当前 IPv4、IPv6 及最近确认的地址变化；
- 最近失败或部分成功的完整探测；
- 等待 Agent 接收、已确认和执行中的中心任务；
- 内存不足、疑似 NAT、上游字段格式变化等需要关注的警告；以及
- 即将发生的计划探测时间。

总览优先呈现异常和近期变化。正常节点与正常探测以紧凑摘要表示，不通过大量
同等权重的卡片占据首屏。

## 空状态与不完整数据

- 全新安装且没有节点时，总览直接提供添加节点入口和生成的一条安装命令，
  不显示由零值指标卡和虚假图表组成的占位仪表盘。
- 节点已注册但没有完整报告时，界面显示连接状态和已经确认的地址，并明确
  标记尚未执行完整探测。在线且资源策略允许时提供节点级手动探测入口，注册
  本身不触发探测。
- 所有节点正常时，总览显示紧凑健康摘要、节点数量和下一次计划时间，不生成
  人为告警或低价值内容填充页面。
- 节点离线时保留最后已知状态，同时显示采集时间和数据可能过期的状态。依赖
  在线 Agent 的操作不可执行，并在操作位置说明原因。
- 部分成功或部分数据缺失时按公网 IP 分别显示成功、失败、跳过和不可用。界面
  不能用空值、零值或默认字段伪装成完整结果。
- 历史被清空时明确显示清空时间，并说明配置和当前状态仍然保留。旧代际离线
  队列不能恢复已清空历史，界面也不暗示会自动执行完整探测。
- 筛选后没有结果时显示“没有匹配记录”和清除筛选操作，与从未产生历史记录
  的空状态明确区分。
- API 或页面加载失败时显示明确失败状态和重试入口，不能转换为空列表或成功
  占位内容。
- 离线队列淘汰或其他已记录历史缺口在时间线上保留显式缺口标记，不能把缺口
  两侧记录展示成连续历史。
