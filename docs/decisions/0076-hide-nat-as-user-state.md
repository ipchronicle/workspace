# ADR 0076：不把 NAT 映射作为用户状态

Status: Accepted

Date: 2026-10-02

Amends: ADR 0031

## 背景

IPChronicle 的用户目标是发现公网出口并查看其 IP 质量。Agent 当前通过本地 TCP
源地址与外部发现服务返回地址的差异，记录一个 `likely_nat` 启发式字段。这个字段
只能说明观察到地址映射或源地址不是全球地址，不能证明存在某个具体 NAT 设备，也
不代表公网出口异常。

## 决策

- NAT 映射不再作为用户可见状态、警告、首页关注项或通知内容。
- NAT 映射不参与公网 IP 归并、可用性判断、探测启用状态、任务目标选择或历史语义。
- 页面继续显示用户有用的公网 IP、可用状态、代理路径和探测结果。
- Agent 和 Center 暂时保留现有 `likely_nat` 字段及数据库列，保证已发布 v0.1.1
  数据可读；它只用于内部地址诊断和日志关联，不新增迁移或改变已发布迁移。
- 地址诊断可以记录本地源地址、外部观察地址、接口、地址族和任务关联。诊断信息
  不应被解释为确定的 NAT 设备识别结果。

## 后果

用户不会再被“经 NAT 到达”误导，也不会把常见的运营商或云网络映射误认为异常。
开发者仍可通过日志调查公网地址发现和立即探测目标不一致的问题。旧数据中的
`likely_nat` 保留但不再影响产品行为，后续若确认不再需要可在新的兼容性评估中移除。

## 备选方案

- 继续显示 NAT 标签：信息对核心任务帮助很小，且启发式误判会干扰用户判断。
- 立即删除字段和数据库列：会扩大已发布版本的数据兼容风险，没有必要。
