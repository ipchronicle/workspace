# ADR 0077：为通知规则增加事件与字段排除范围

Status: Accepted

Date: 2026-10-02

## 背景

通知规则已有单个事件类型或“全部事件”的匹配范围，但用户无法在保留大范围
通知的同时排除不关心的事件。探测字段变化还需要按报告语义区分网络分类、风险
评分、风险因子、邮件连通性和媒体服务，不能按底层数据源名称跨区域合并。

## 决策

- 保留现有事件范围字段，在规则上增加事件类型排除集合和字段范围排除集合。
- 顶层事件使用稳定事件类型；探测字段使用语义范围路径，例如
  `Type/ipapi` 和 `Type/ipapi/company`。
- 同名数据源在不同报告区域是不同范围，`网络分类 → ipapi` 不影响
  `风险评分 → ipapi`。
- 父范围排除当前及未来加入该范围的子字段。
- 一次探测同时产生多个字段变化时，先移除排除字段；剩余字段仍发送，全部被排除
  时不创建字段变化投递。
- 排除只影响通知匹配，不影响报告、历史、原始字段变化或其他数据保留。
- 已有规则的排除集合为空，升级后保持原有行为。

## 后果

用户可以用一条“全部事件”规则排除地址检查失败、邮件连通性或某个媒体字段，
同时继续接收其余事件。配置库需要新增有序迁移；字段目录 API 需要提供稳定的
语义范围路径，前端据此显示可展开的中英文树。
