# ADR 0074：使用节点恢复密钥接管原有身份

Status: Accepted

Date: 2026-09-04

Supersedes: ADR 0007 中删除本地状态后只能创建新节点的决定

## 背景

`v0.1.1` 的通用注册密钥只会创建新节点。节点重装系统或丢失 Agent 本地状态后，
再次注册会得到新的节点 ID，原节点的计划、代理、公网 IP 关联和历史无法继续使用。
主机名和硬件指纹既不可靠，也可能误合并不同主机，不能作为自动恢复依据。

## 决策

- 每个节点拥有独立的高熵恢复密钥。恢复密钥长期可重复使用，并可由管理员主动
  轮换；不复用通用注册密钥或日常 Agent Token。
- Center 保存恢复密钥摘要用于校验，并使用安装主密钥保存加密副本，以便管理员
  再次查看节点专属安装命令。轮换后旧命令立即失效。
- 节点专属安装命令仍调用官方安装器，由安装器解析当前发行通道和 Agent 版本；
  Center 不把具体 Agent 版本写入命令。
- 恢复使用独立 Agent API。即使旧 Agent 在线，持有恢复密钥的新安装也会立即、
  原子地接管节点：签发新日常凭据、撤销旧凭据，并使旧 Agent 下次请求时停止。
- 成功恢复不自动轮换恢复密钥。已撤销或等待永久删除的节点拒绝恢复；禁用节点可以
  恢复，但仍保持禁用。
- 恢复保留节点 ID、名称、启用状态、探测计划、代理配置、日志等级、公网 IP 关联
  和全部 Center 历史。
- 恢复结束旧 Agent 的未完成任务，将已应用配置 revision 重置为 0，并清除旧主机
  能力、网卡与路由库存、内存和当前发现路径。新 Agent 必须重新上报这些主机事实。
- 只有已经上传到 Center 的数据能够恢复；旧系统盘上尚未上传的日志、地址事件或
  探测结果不属于 Center 恢复范围。
- 恢复、轮换和失败尝试写入不含凭据的安全事件。公开恢复接口沿用 Agent 注册接口
  的速率限制，不泄露密钥是否接近有效或节点是否存在。
- 注册和恢复接口共享按 Center 所见 TCP 对端地址计算的内存限速，每分钟允许 120 次
  请求。该额度允许集中反向代理后的节点批量安装；Center 不信任客户端提供的转发
  地址头。限速状态不持久化，Center 重启后重置。

## 后果

- `v0.1.1` 的现有节点需要通过新的有序配置库迁移补齐恢复密钥，不能重写初始
  迁移。
- 恢复密钥泄露即允许接管节点身份；管理员必须像安装凭据一样保护专属命令。
- 恢复不是主机备份。Center 不尝试恢复旧系统盘的 Agent 离线队列。
- 通用注册仍只创建新节点，避免根据可变主机特征做隐式合并。

## 备选方案

### 按主机名、机器 ID 或硬件指纹自动关联

未采用。这些值可能重复、变化或被克隆，误接管比显式恢复更危险。

### 恢复前要求在 Center 二次确认

未采用。节点专属高熵密钥已经是明确授权，额外交互会破坏重装后的一条命令恢复。

### 每次恢复后自动轮换密钥

未采用。一次性语义会让保存的专属命令迅速失效，增加没有实际收益的运维步骤。
